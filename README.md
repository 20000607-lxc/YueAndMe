# Yue & Sherry

越越在济南，Sherry 在旧金山。两个人的摄影作品站。

## 本地预览 + 管理面板

在这个文件夹里运行：

```
python3 scripts/admin.py
```

然后浏览器打开：

- 网站：http://localhost:8765
- 管理面板：http://localhost:8765/admin

管理面板能做的事：

- **拖拽排序**：拖动照片调整先后顺序，网页上的顺序随之改变。
- **换地点**：把照片拖到另一列，就会把原图、大图、缩略图都挪到那个地点文件夹。
- **新建地点**：右侧输入名字，比如「青岛」，就会建出 `originals/越越/青岛/`。
- **上传**：从 Finder 把图片直接拖进某一列，自动压图并加入。支持 JPG、PNG、HEIC。
- **写标题和说明**：点一张照片，右侧填标题、日期、一句话说明，离开输入框即保存。
- **移出网站**：原图会挪到 `originals/_已移除/` 而不是删除，想找回去那里拿。

所有改动都直接写进 `js/photos.js` 和文件夹，没有别的数据库。
按 Ctrl+C 停止服务。

## 不用面板，手动加照片

1. 把原图放进 `originals/作者/地点/`，例如 `originals/Sherry/旧金山/金门.jpg`。
   作者文件夹名要和网页上的名字一致（`越越`、`Sherry`），地点随意，多少个都行。
2. 运行 `python3 scripts/build_photos.py`，它会压出网页大图（长边 2000px）和缩略图（长边 900px），
   并更新 `js/photos.js`。原图不会被改动。已有的标题、说明和顺序会保留。
3. 直接编辑 `js/photos.js` 也可以改标题和顺序，文件里的先后顺序就是网页上的顺序。

## 改文字

- 首页诗句、两座城市的介绍、「关于我们」的文字都在 `index.html` 里，直接改。
- 配色和字体在 `css/style.css` 最上面的 `:root` 里。

## 以后上线

整个文件夹就是一个纯静态站，不依赖任何构建工具。
推到 GitHub 开 Pages，或拖进 Netlify / Vercel 就能上线。
注意 `originals/` 里是原图，`scripts/` 是本地工具，上线时都不需要带上。
